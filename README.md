# 🎯 Wortratespiel

Ein einfaches, unterhaltsames Wortratespiel mit JavaFX – entwickelt als Desktop-Anwendung.  
Das Spiel wurde in **Java 23** mit **JavaFX 25** erstellt und kann unter Windows als eigenständiges Programm (ohne zusätzliche Installation von Java) ausgeführt werden.

---

## 🚀 Features
- intuitive grafische Oberfläche (JavaFX)
- spielerisches Wortraten mit Zufallswörtern
- eigenständige ausführbare `.exe` (inklusive eingebettetem JRE)
- keine Java-Installation erforderlich
- einfache portable Version ohne Setup

---

## 🧩 Voraussetzungen
Für das **Spielen** sind keine weiteren Installationen nötig –  
die ausführbare Version enthält bereits eine Java-Laufzeitumgebung.

Zum **Bauen des Projekts** aus dem Quellcode wird benötigt:
- Java JDK 23+
- Maven 3.9+

---


## ▶️ Ausführen unter Windows

1. Lade das Archiv `Wortratespiel.zip` herunter.  
2. Entpacke es an einem beliebigen Ort.  
3. Doppelklicke **`Wortratespiel.exe`**.  
   → Das Spiel startet sofort 🎉
